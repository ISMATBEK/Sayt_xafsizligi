📱 APK faylni qanday tahlil qilish mumkin?

APK faylni tahlil qilish uchun:

  1. APK Analyzer bo'limiga o'ting
  2. "Fayl tanlash" tugmasini bosing
  3. APK faylingizni tanlang (maksimal 10MB)
  4. "Tahlil qilish" tugmasini bosing
  5. Natijalarni kuting (bir necha soniya)

Faqat .apk kengaytmali fayllar qabul qilinadi!

🌐 Website scanner qanday ishlaydi?

Website scanner quyidagilarni tekshiradi:

  • SSL/HTTPS mavjudligi
  • Xavfsizlik headerlari (X-Frame-Options, HSTS)
  • Server ma'lumotlari
  • Ochiq portlar
  • Xavfli sozlamalar

📊 Test natijalari qanday hisoblanadi?

Test 20 ta savoldan iborat. Har bir to'g'ri javob 5 ball. Maksimal ball 100.

Natijalar:

  • 80-100 ball - Ajoyib
  • 60-79 ball - Yaxshi
  • 40-59 ball - Qoniqarli
  • 0-39 ball - O'rganish kerak

🔐 Parol generator qanday ishlaydi?

Parol generator quyidagi parametrlar asosida xavfsiz parol yaratadi:

  • Katta harflar (A-Z)
  • Kichik harflar (a-z)
  • Raqamlar (0-9)
  • Maxsus belgilar (!@#$%)

⚠️ Xavfli linklarni qanday aniqlash mumkin?

Xavfli linklarning belgilari:

  • Soxta domenlar (g00gle.com, faceb00k.com)
  • Shoshilinch xabarlar
  • Sovrin yutdingiz degan va'dalar
  • Grammatik xatolar
  • HTTP (xavfsiz emas) ishlatilishi
